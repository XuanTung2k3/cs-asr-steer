# SRD2-G0 reference firewall and independent audits

This freeze is metadata/source/CPU-math only. Historical aggregate reports may motivate a new
prospective study, but no new lexical outcome/reference transcript is inspected here. Previous
180 positions and their FULL300 utterance parents are excluded from new outcome evaluation.

## Input separation

Preparation reads only the six role metadata columns recorded by the inventory. Historical
exposure artifacts are projected to IDs for exclusion only; lexical text/metrics cannot affect
ranking. Raw role/exposure files are hash-pinned but are not runtime inputs.

The runner receives a newly serialized safe projection containing **only** canonical_index,
utterance_id,audio_path,audio_full_sha256. It rejects extra fields recursively rather than
accepting and ignoring target/stratum fields. Do not pass SRD2_G0_POPULATION.json directly: its
roster/exclusion/dialogue metadata are not inference features. Query records generated in Job A
may carry baseline IDs/prefixes, query/cache positions, audio/model hashes and reference-free gate
components; they contain no gold surface, target set, correctness/stratum, CTC/MMS-FA or oracle.

D2 may use readout gradients of its own EN/ZH script-mass objective. It cannot receive evaluator
lexical gradients, reference tokens, acceptable-token sets, competitors derived from references,
future generated tokens or oracle windows. Model weights never change. Full causal B0 replay
is allowed for R2; later-token independence must be audited, not assumed from a filename.

Dialogue identity is post-processing/cluster metadata, never a gate feature. The shuffled control
uses the same utterance's complete eligible query list and includes zero values. It never uses
held-out roles or label-conditioned donor assignment. No input CTC/MMS-FA files are required.

No stage may continue on failed audit, missing remote seal or changed pins. Keep failed/invalid
attempts and opened-path logs intact. No automatic job rerun, population reduction or role refill.

## Independent auditor restrictions

Read frozen config/artifacts and safe identity metadata. Sharing mechanical hash/array readers is
allowed. **Do not import primary gate-wrapper, shuffle, evaluator or decision logic.** Independently
apply original RAW-logit partition math, ten-head normalization/window/tie/sample bounds, native
LID/null formula, query identity, deterministic donor ordering, dose/energy/restore tests and
predicate AST. Verify no optimizer, parameter grads, surviving hooks/cache alias, unrelated model
or dataset, and no outcome information in global authorization. Independently validate the
old30 apparatus set separately from the400 new outcomes. Compare source/process file-open logs
against explicit allowlists, rather than looking only for suspicious key names in one JSON.

PRIMARY verifies complete raw data and sealed pulse identities **without** lexical references.
FULL is a separate process; its reference input paths cannot be reachable from either runner.
Absence of a reference string in a final record alone is not proof that inference was label-free.
