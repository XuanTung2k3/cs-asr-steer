# S1 reference firewall and seal barrier

Scope: existing exposed D-dev-select historical180 only; no new model outcomes in freeze.
No training, gradients, vectors, activation edits, full-decoding intervention, oracle regions,
D-dev-confirm, D-test, router-calib new role, P3 or transfer datasets.

## Phase permissions

A. Preparation/original candidates: allow audio by80 UID/hash, frozen B0 content[:t], query,
model/processor/config, R0 primary windows/EN-ZH-U intervals, existing original M logits.
AUTO language detection is original audio only, not a target label. Strata/count metadata are
not per-row provider inputs. Archive runtime projection separately from evaluation metadata.
Deny references, acceptable-token sets, fixed evaluator competitors, POI/error labels, gold
word timings, oracle region masks, R0 oracle_analysis*, MMS-FA timing proxy and script masks.
Candidate and region choice do not use logits from a mask or any evaluator quantity.

B. Candidate seal: push immutable distributions/candidate identities/original attention/bounds,
source/model/config hashes and manifest. Verify remote contains seal. Independent CANDIDATES
PASS before acoustic phase. Failed attempts preserved, no mutation or reselection.

C. Acoustic pass: allow immutable candidate projection, original waveform/region records and
historical reference-free LAC masked arrays. Only rescore SEALED IDs. Counterfactuals cannot
change AUTO language token, union membership, original attention or query. Entire masked
encoder and cold same-prefix M owner cache; no original/cross-mask decoder cache sharing.
Archive all180 rows/statuses including abstentions, not only candidate-rich or favorable queries.

D. Full seal: push candidates+acoustic outputs+all diagnostics/manifest/hash chain. Remote seal
must be confirmed before evaluator launch. File-open auditing covers both scientific jobs;
model weights immutable, no steering hooks. Runner cannot import evaluators or oracle constructors.

E. PRIMARY audit: no references; independently verify projection, unions, numerical readouts,
region/control rule, outside waveform bytes, horizons, cache ownership, fixed scoring, exact
historical LAC reuse and complete coverage. PASS does not assert H or D success.

F. Evaluator: only after D/E, allow existing P2-RJ targets/strata/structural alignment metadata.
Reference first-token sets define hits and paired-accessible **analysis** only. No updated region,
source, candidate, lambda, threshold or mask decision may return to runtime. Conditional ranking
on accessible gold targets is not a deployable selector. Do not construct gold timing masks.

G. FULL independent audit recomputes all counts, paired dialogue uncertainty and terminal labels.
Auditor must not import primary decision logic, top-K/mask-selection/score implementation. Generic
hash/array IO is allowed. Only S1_READY_FOR_S2 recommends a separately frozen S2 design; no S2 run.

## Immutable chain

Design -> PASS_TO_S1 and plan/manifest -> original candidate seal pushed -> CANDIDATES PASS ->
acoustic seal pushed -> PRIMARY PASS -> exposed-reference evaluation -> FULL PASS/terminal label.
Record git ancestry and remote hashes at each transition. No automatic job resubmission to repair
science; mechanical fixes preserve failed artifacts and require a new audit. Reuse requires exact
input/model/source/preprocessing/suppression hashes; any changed semantics is a blocker/invalidity.

CPU design tests check panel/provenance and contract invariants using existing metadata and synthetic
values only. They are not a substitute for executable lineage, no-leakage or outcome audits.
